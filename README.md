# TasteToShare

TasteToShare is a Kotlin-based Android app for discovering, saving, and sharing food and drink experiences with friends and fellow food lovers. It helps users explore recipes, manage favorites, follow community activity, and discover nearby food-related experiences.

## Features
- Browse and discover recipes and food experiences
- Save favorite dishes and personal collections
- Create and edit recipes
- View detailed recipe information and reviews
- Manage user profile and preferences
- Explore maps and locations tied to food experiences
- Receive notifications for new activity and recommendations
- Shopping list and personal organization tools

## Tech Stack
- Kotlin / Android Jetpack
- Firebase for authentication and cloud data
- Firebase Cloud Functions for backend automation and notifications
- Gradle-based Android project structure
- Material UI / Compose-style Android screens

## Project Structure
- `app/` — Android application source and resources
- `app/src/main/java/com/example/tastetoshare/` — app logic, screens, navigation, repositories, services, and view models
- `functions/` — Firebase Cloud Functions for notifications and backend logic
- `videos/` — project demo or presentation assets

## Getting Started
1. Clone the repository
2. Open the project in Android Studio
3. Sync Gradle dependencies
4. Ensure Firebase configuration is set up (including `google-services.json`)
5. Run the app on an Android emulator or device

## Notes
This project is primarily Kotlin-heavy, with Firebase and backend functions supporting social sharing, notifications, and recipe-related workflows.
